# Финальный проект — блок Python

Анализ `data.csv` — товарооборот по складам и контрагентам, плюс
сопоставление продаж с погодой.

## Что внутри
| Файл | Что это |
|---|---|
| `анализ_продаж_и_погоды.py` | разбор data.csv, динамика продаж, связь с температурой |
| `анализ_клиентской_базы.py` | разбор клиентской базы |
| `Блок 3 (шаблон курса).ipynb` | шаблон, приложенный к уроку |
| `данные/data.csv` | 419 тыс. строк продаж |
| `данные/погода_астана_2018.csv` | суточная температура |

## ⚠️ Блок не закрыт полностью
Задание говорит: «Вам даны данные data.csv. Ответьте на все вопросы в
файле», и ссылается на документ в Google Drive, к которому нет доступа.
**Точный список вопросов неизвестен**, поэтому здесь — анализ данных по
существу, а не построчные ответы.

Как только документ с вопросами будет доступен, решение нужно
пересобрать под них.
