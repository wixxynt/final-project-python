--------------------------------------------------------------------------------
1. Прочитать данные в df (pd.read_csv), вывести первые строки.
   ОТВЕТ: df прочитан, 301 355 строк x 5 столбцов (Дата, Склад, Контрагент,
   Номенклатура, Количество). Период 04.01.2018 — 31.08.2018.

2. Проверить формат столбцов.
   ОТВЕТ: пропусков нет ни в одном столбце. Склад = int64, значения 1..5.
   Количество = int64. Контрагент (211 уник.) и Номенклатура (24 уник.) — строки.
   Дата прочиталась как СТРОКА — единственный столбец в неправильном формате.

3. Перевести столбец «Дата» в правильный формат.
   ОТВЕТ: pd.to_datetime(df["Дата"], format="%Y-%m-%d") -> datetime64.
   Уникальных дат: 205 (при 240 календарных днях в периоде).

4. Сгруппировать по дате, посчитать количество продаж -> grouped_df.
   ОТВЕТ: grouped_df = 205 строк x 3 столбца.
   «Количество продаж» = число сделок (строк) за день, через size().
   Дополнительно «Сумма штук» = сумма Количество за день.
   Среднее 1470.0 продаж/день, медиана 1448, min 1164, max 1840, std 102.3.

5. Вывести первые строки grouped_df.
   ОТВЕТ: выведены (grouped_df.head(10)), первая дата 2018-01-04 — 1840 продаж.

6. Нарисовать график продаж у grouped_df.
   ОТВЕТ: построен линейный график по дням + скользящее среднее за 7 дней
   + линия среднего (1470). График сохранён в выводе ячейки как PNG.

7. Описать что видно на графике (максимально подробно).
   ОТВЕТ (опорные цифры, все посчитаны в блокноте):
   - Пропущено 35 календарных дней из 240. Из них 34 — ПОНЕДЕЛЬНИКИ (все
     понедельники периода), 35-й — четверг 22.03.2018 (Наурыз). Это не дыры
     в данных, а нерабочие дни.
   - Тренда нет: наклон +0.0266 продаж/день = +5.5 продаж за 8 месяцев;
     корреляция с номером дня +0.015; первые 30 дней 1510 vs последние 30 — 1503.
   - Разброс узкий: std 102.3, коэффициент вариации 7.0 %.
   - Главный паттерн — недельный цикл, эффект вторника:
       Вторник     1643.3 (среднее)
       Четверг     1456.1
       Пятница     1455.6
       Среда       1437.0
       Суббота     1418.1
       Воскресенье 1410.5
     Вторник выше остальных дней на ~190 продаж (+13 %); остальные дни между
     собой почти не различаются (разброс < 4 %). Воскресенье НЕ проваливается.
   - Месячной сезонности нет: янв 1514, фев 1466, мар 1448, апр 1431, май 1470,
     июн 1471, июл 1462, авг 1498 — размах 83 продажи (~6 %).
   - Пики вверх: 04.01 — 1840 (чт, первый день после каникул, +3.6 сигмы);
     31.07 — 1765, 14.08 — 1759, 23.01 — 1746, 28.08 — 1731 (все ВТОРНИКИ).
   - Провал вниз: 18.04.2018 — 1164 (среда), на 19 % ниже медианы своей среды.
     Единственная настоящая аномалия вниз, требует уточнения у источника.

8. Найти строку с максимальным выбросом по количеству продаж (у df).
   ОПРЕДЕЛЕНИЕ ВЫБРОСА: проверены три критерия — IQR, z-оценка, максимум.
   Q1=1, Q3=4, IQR=3, граница Q3+1.5*IQR = 8.5 шт -> 13 140 строк (4.4 %) —
   порог слишком мягкий; z > 3 -> 5 322 строки; максимальная z = 65.7.
   ОТВЕТ (строка с индексом 218822):
       Дата         2018-06-28
       Склад        1
       Контрагент   address_208
       Номенклатура product_0
       Количество   200
   Медиана Количество = 2, среднее 2.95, 75-й процентиль 4. То есть 200 штук —
   в 100 раз выше медианы, z = 65.7. Вторая по величине сделка — 140 шт
   (31.07, склад 4), отрыв лидера 43 %.

9. Топовый товар по продажам по средам за июнь/июль/август у 3 склада.
   ФИЛЬТР: Склад == 3 (столбец int64, сравниваем с числом), .dt.weekday == 2
   (среда), .dt.month.isin([6,7,8]). Отобрано 4 345 строк за 13 сред
   (06/13/20/27.06, 04/11/18/25.07, 01/08/15/22/29.08).
   ОТВЕТ: product_1 — 2 267 шт. суммарно.
   Рейтинг: product_1 2267, product_2 2060, product_0 1324, product_3 914,

10. Погода с rp5.ru -> Дата + средняя температура за день, объединить с
    grouped_df, график y=['Количество продаж','T'] + отдельный график температуры.
    ПРЕОБРАЗОВАНИЕ: исходный файл rp5 — sep=';', 6 служебных строк с '#'
    (skiprows=6), index_col=False (иначе лишняя ';' в шапке уводит первый
    столбец в индекс), время формата '31.08.2018 23:00' по 3 часа
    (1 918 замеров, 8 в сутки, в один день 6). Группировка по дню, среднее по T.
    Результат: 240 дней, T без пропусков. Совпадает с готовым файлом
    погода_астана_2018.csv до 0.0 градуса.
    ОБЪЕДИНЕНИЕ: погода — 240 дней (04.01—31.08), продажи — 205 дней (тот же
    интервал). Левый merge по «Дата» от grouped_df -> 205 строк, температура
    нашлась для ВСЕХ 205 (0 пропусков). 35 дней погоды не попали в итог —
    это 34 понедельника + 22 марта, когда продаж не было.
    ГРАФИКИ: (а) совмещённый «Количество продаж» + «T» на двух осях;
             (б) отдельный график средней суточной температуры.
    ЧИСЛА: корреляция продаж и температуры — Пирсон r = -0.024,
    Спирмен rho = +0.002, то есть статистический ноль.
    Средняя T по месяцам: янв -19.5, фев -13.8, мар -7.6, апр +5.0, май +10.3,
    июн +18.6, июл +21.5, авг +18.3.

    и +27.1 (09.07, пн); по 205 дням с продажами: -33.2 (23.01) и +27.0 (09.08).
    ВЫВОД: температура НЕ объясняет динамику продаж. Драйвер колебаний —
    рабочий календарь (нерабочий понедельник, пик во вторник).
